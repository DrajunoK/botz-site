# botz-site

Mini site web statique pour l'app **Botz**.

Ce repo ne contient que le site (page d'accueil + politique de confidentialité), pas le code de l'app.

- `index.html`: page d'accueil
- `privacy.html`: politique de confidentialité
- `style.css`: styles
- `CNAME`: domaine `botz.pomponlabs.com` (GitHub Pages)
